title Alur Register (Daftar) Sederhana

participant Pengguna
participant Aplikasi
participant Server

Pengguna->Aplikasi: Isi nama, email, password, konfirmasi password
Pengguna->Aplikasi: Tekan tombol Create Account
Aplikasi->Server: Kirim data pendaftaran

alt Register berhasil
  Server-->Aplikasi: Status berhasil + data akun
  Aplikasi->Pengguna: Tampilkan pesan "Pendaftaran berhasil"
  Aplikasi->Pengguna: Arahkan ke halaman Login
else Register gagal
  Server-->Aplikasi: Status gagal + pesan error
  Aplikasi->Pengguna: Tampilkan pesan gagal daftar
end
