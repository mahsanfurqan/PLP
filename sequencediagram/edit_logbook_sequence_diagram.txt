title Alur Edit Logbook Sederhana

participant Pengguna
participant Aplikasi
participant Server

Pengguna->Aplikasi: Buka daftar logbook
Pengguna->Aplikasi: Pilih logbook lalu tekan Edit
Pengguna->Aplikasi: Ubah data logbook
Pengguna->Aplikasi: Tekan tombol Simpan
Aplikasi->Server: Kirim perubahan data logbook

alt Update berhasil
  Server-->Aplikasi: Status berhasil
  Aplikasi->Pengguna: Tampilkan pesan "Logbook berhasil diperbarui"
  Aplikasi->Pengguna: Tampilkan data logbook terbaru
else Update gagal
  Server-->Aplikasi: Status gagal + pesan error
  Aplikasi->Pengguna: Tampilkan pesan gagal update logbook
end
